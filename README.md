# Куда ушли деньги

Личный трекер трат. Работает целиком в браузере, без сервера и без регистрации.
Данные хранятся в памяти браузера на твоём устройстве.

## Что внутри

- index.html — само приложение
- sw.js — офлайн-режим
- manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png — иконка и настройки для домашнего экрана

Все файлы должны лежать рядом, в одной папке.

## Как выложить на GitHub Pages

1. Создать репозиторий, например traty.
2. Загрузить туда все файлы из этой папки (Add file → Upload files).
3. Settings → Pages → Source: Deploy from a branch, ветка main, папка / (root), Save.
4. Через пару минут адрес будет вида https://ИМЯ.github.io/traty/

Репозиторий можно оставить публичным: кода там нет ничего личного, а траты
хранятся только в браузере и в репозиторий не попадают.

## Как поставить на айфон

Открыть адрес в Safari, нажать «Поделиться» → «На экран Домой».
Приложение откроется на весь экран, без адресной строки, и будет работать без интернета.

Важно: ставить именно с домашнего экрана. Safari удаляет данные сайтов,
на которые не заходили 7 дней, а приложения с домашнего экрана под это правило не попадают.

## Синхронизация через Firebase

Записи будут храниться в твоём проекте Firebase и сами разъезжаться между телефоном
и компьютером. Настраивается один раз, примерно на десять минут.

1. console.firebase.google.com → Add project. Google Analytics можно не включать.
2. Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save.
3. Build → Firestore Database → Create database → Start in production mode, регион europe-west.
4. Вкладка Rules, вставить и нажать Publish:

       rules_version = '2';
       service cloud.firestore {
         match /databases/{database}/documents {
           match /users/{uid} {
             allow read, write: if request.auth != null && request.auth.uid == uid;
           }
         }
       }

5. Project settings (шестерёнка) → раздел Your apps → значок Web (</>) → зарегистрировать
   приложение → скопировать объект firebaseConfig целиком, от { до }.
6. В приложении: «Данные и настройки» → вставить объект в поле Firebase, ввести почту
   и пароль, нажать «Создать вход». На втором устройстве вставить тот же объект
   и войти той же почтой — данные подтянутся.

Тариф Spark бесплатный, для личного учёта лимиты не выбираются.
Добавь домен GitHub Pages в Authentication → Settings → Authorized domains,
иначе вход с сайта будет отклонён.

### Как работает слияние

Каждая запись помечается временем изменения. При встрече двух версий побеждает та,
что новее. Удалённая запись помечается как удалённая, а не стирается, поэтому она
не воскресает при синхронизации с другого устройства. Без сети всё пишется локально
и уходит в облако, когда сеть появится.

Всё лежит в одном документе Firestore. Ограничение документа — 1 МБ, это порядка
5000 операций. Когда подойдёшь к этому, записи надо будет разложить по месяцам.

## Бэкапы

Даже с облаком копии не лишние: они защищают от случайного удаления,
которое синхронизация честно повторит на всех устройствах.

Раз в пару недель заходи в «Данные и настройки» → «Сохранить копию».
Получится JSON-файл — отправь его себе в облако или в мессенджер.
Восстановление там же, кнопкой «Восстановить из копии».
Приложение само напомнит, если копии нет больше 14 дней.

## Ключ API (необязательно)

Без ключа новые места раскладываются по встроенному словарю, остальное приложение
спрашивает у тебя один раз. Если вставить ключ Anthropic в настройках, незнакомые
места будут распределяться по разделам автоматически. Ключ лежит только в твоём браузере.
